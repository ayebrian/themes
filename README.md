# Themes

## 1. ChatGPT
This theme provides a dynamic coloring based on your chosen color scheme.

Version 2.0.0 is a rewrite for the new ChatGPT design (October 2026). The whole palette is derived from one accent color per mode, so every surface, menu, border and text color follows it.

### Options
All options are available in the Stylus style settings:

- **Accent color (dark / light)**: the base color for each mode
- **Background tint strength**: from neutral gray (0) to the default tint (1) and beyond
- **Tint text with the accent color**: tinted or neutral text
- **Sidebar**: same as chat, darker or much darker
- **OLED black background**: pure black background in dark mode
- **Dynamic user message color**: colored user messages, or ChatGPT's native gray
- **User message color**: the accent color or a custom color
- **Send and voice buttons**: neutral or accent colored
- **Chat width**: default, wide, wider or full width
- **Corner roundness**: from square (0) to the default (1)
- **Font family / Code font family**: any installed font (`native` keeps ChatGPT's font)
- **Hide**: the disclaimer under the composer, the Chat / Work switch, the suggestions under the composer

### Notes
- The theme overrides the colors from ChatGPT's **Settings → Appearance** (Theme, Accent, Background, Foreground, Contrast). Font size, Reduce motion and Diff markers still work as usual.
- Background tint strength and text tinting need a browser with CSS relative color support (Chrome 119+, Firefox 128+, Safari 16.4+).
- Only the logged-in ChatGPT is themed.
